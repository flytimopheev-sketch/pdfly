# pdfly 0.2.0

Первый релиз под именем **pdfly**.

![Главное окно pdfly](https://raw.githubusercontent.com/flytimopheev-sketch/pdfly/v0.2.0/docs/screenshots/pdfly-main.png)

## Что нового

- Проект, приложение, RPM-пакет, desktop-файл, иконка и репозиторий
  переименованы в **pdfly**.
- Интерфейс приложения полностью переведён на русский: меню, панель
  инструментов, диалог печати, сообщения об ошибках и прогресс CUPS.
- Добавлен поворот текущей страницы по часовой и против часовой стрелки,
  а также сброс поворота. Поворот влияет только на просмотр и не изменяет
  исходный PDF.
- Добавлены полноэкранный режим (F11/Esc) и диалог свойств документа.
- Добавлен русский README и обновлён английский: бейджи, скриншоты,
  архитектура, установка, горячие клавиши и ограничения XFA.
- Новая иконка и компактная панель инструментов с системными иконками.
- Добавлен диалог «О программе pdfly».
- Добавлены реальные скриншоты приложения в `docs/screenshots/`.
- Статические XFA-формы, XFA-пагинация, аннотации и печать CUPS в режимах
  direct/flatten сохранены.

## Установка

```bash
sudo dnf install ./pdfly-0.2.0-1.red80.x86_64.rpm
pdfly --version
pdfly
```

Пакет собран для RedOS 8 x86_64. PDF4QT Core 1.6.0.0 поставляется внутри
RPM в `/usr/lib64/pdfly`, поэтому отдельная установка PDF4QT не требуется.

## Проверено

- RedOS 8 x86_64, GCC 13.3.1, Qt 6.9.3, CUPS 2.4.20.
- PDF4QT Core 1.6.0.0, commit `67b6b99`.
- Offscreen smoke-тесты: обычный PDF, статическая XFA, переразбиение XFA,
  flatten и CUPS direct/flatten/multi-document.

## Ограничения

pdfly — просмотрщик только для чтения. Динамический XFA, скрипты,
FormCalc, привязка данных и редактирование полей не поддерживаются.
PDF4QT разбирает только статический `template`; подробнее — в
[README](https://github.com/flytimopheev-sketch/pdfly#xfa-что-поддерживается).
